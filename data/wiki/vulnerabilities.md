# Виртуальные уязвимости

Это вымышленные классы уязвимостей внутренней сети mesh. Они существуют
только в симуляции и нужны для прохождения миссий.

| Название | Механика в игре | Противодействие |
|---|---|---|
| `WEAK-KEY` | словарный пароль узла | `hack <узел>` за 1–3 попытки |
| `LOG-LEAK` | пароль в скрытом логе | `ls -a`, затем `cat auth.log` |
| `FW-BYPASS` | файрвол пропускает токен | `sniff` → `firewall --bypass <token>` |
| `GHOST-PROC` | чужой демон держит порт | `hack <узел>` после `connect` |
| `PLAIN-VAULT` | архив без соли | `decrypt vault.enc` |
| `HONEY-POT` | узел-приманка | `net-scan`, не хранить ключ на нём |
| `ROT-PWN` | бот меняет пароль каждые N тиков | атаковать сразу после `bot-status` |

Бот в песочнице сам использует `WEAK-KEY`, `ROT-PWN` и `VIRUS-PAYLOAD`,
поэтому выигрыш требует скорости, а не одного удачного взлома.
