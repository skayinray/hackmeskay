# Серверная империя

Империя — дерево виртуальных нод, хранящееся в `saves/empire.sqlite3`.

```
empire build              # gateway -> vpn/c2 -> mainframe
empire status             # список нод
/scan 10.60.4.12          # версии сервисов и уязвимости (симуляция)
/trace 10.60.4.12         # распутать VPN/C2-цепочку
breach 10.60.4.12 --captcha
empire rootkit <node_id>  # руткит подменяет врагу логи
```

## Типы нод
- **Gateway** — единственные видимые наружу узлы; файрвол + капча.
- **VPN/C2** — скрытые узлы, удлиняют цепочку маршрута.
- **Mainframe** — хранит крипту и файлы; IP виден только после `/trace`.

Руткит на прокси подменяет вывод `/scan` и добавляет ложный след в
`/trace` — противник тратит ходы на пустой узел.

Механики `/scan`, `/trace` и `breach` работают с локальной SQLite-моделью.
Реальные сетевые запросы к указанным IP НЕ выполняются.
