# Сетевая игра и Messenger ID

## Создать комнату
```
host 45678
```
Хост поднимает asyncio-сервер на `0.0.0.0:45678`. Игроку выдаётся
постоянный `Messenger ID` вида `skay_user_9fk21ab03c` — он хранится в
`config/identity.json` и не меняется при перезапуске.

## Присоединиться по IP
```
join 192.168.1.42 45678
```
Клиент подключается по реальному LAN-IP только один раз. После handshake
в интерфейсе отображаются только Messenger ID.

## Шифрование
X25519 (ephemeral) → HKDF-SHA256 → AESGCM. Каждое направление имеет
свой счётчик nonce. Хост ретранслирует сообщения по ID получателя.

## Мессенджер
```
id                       # ваш ID
peers                    # список участников
msg skay_user_xxx привет # личное сообщение
leave                    # выйти из комнаты
```

Все команды можно вводить с `/`: `/help /scan`.

Атаки проводятся только над виртуальными IP Серверных Империй
(`10.60.x.y`) и не выходят в реальную сеть.
