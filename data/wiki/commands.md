# Синтаксис команд

Команды вводятся в нижнем регистре, аргументы разделяются пробелами.
Поддерживаются кавычки: `connect "node 01"`.

## Глобальные
| Команда | Назначение |
|---|---|
| `help [тема]` | список команд / открыть статью |
| `wiki [тема]` | база знаний |
| `mod list\|enable\|disable\|reload <name>` | управление модами |
| `update check\|install` | обновления |
| `mode <name>` | прямой переход между режимами |
| `save` / `quit` | сейв / выход |

## Сетевые (в режимах)
- `ls [-a]` — список файлов (с `-a` видны скрытые);
- `cd <путь>` — смена каталога;
- `net-scan` — обнаружить узлы виртуальной сети;
- `connect <узел> [пароль]` — открыть сессию;
- `hack <узел> [--brute|--swarm]` — подобрать ключ;
- `sniff`, `firewall --bypass <token>`, `proxy`, `decrypt <файл>` — кампания;
- `virus-clean <узел>`, `bot-status` — песочница.
