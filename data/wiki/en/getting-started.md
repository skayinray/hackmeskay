# Quick start

1. In the main menu type `tutorial` to complete the five-step tutorial.
2. Then type `campaign` and `mission start 1`.
3. Type `sandbox 3` for endless play against a level 3 AI bot.

Useful commands:

- `help` lists the commands available in the current mode;
- `wiki <topic>` opens a knowledge base article;
- `save` forces progress to be written to `saves/`;
- `quit` exits the game.

Everything in the game is a simulation of an internal virtual mesh network.
